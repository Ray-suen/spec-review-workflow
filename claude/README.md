# Claude Entry

This folder packages the workflow for Claude Code.

## Files

- `CLAUDE.md` for project instructions
- `.claude/commands/spec-review-workflow.md` for a slash command entry

## Usage

Copy the workflow files into the target Claude project:

- `core/` -> project root `core/`
- `claude/CLAUDE.md` -> project root `CLAUDE.md`
- `claude/.claude/commands/spec-review-workflow.md` -> project root `.claude/commands/spec-review-workflow.md`

Then use the command inside Claude Code when you want the workflow to start.
